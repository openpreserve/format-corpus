## About these files

Sample Inmagic DB/TextWorks 7.0 files. Created using Inmagic DB/TextWorks 7.01, running on Windows XP. Note that DB/TextWorks uses a composite file format, i.e. a single database is made up several different files. Each subdirectory of this folder contains one database.
